Karaoke Mode Mingslep

Synchronized lyrics are resolved in real time via LRCLIB and centered cleanly in a single line. The island dynamically breathes in and out to match the length of the vocal phrase.

Native C# WPF Performance

Adaptive Morphing Geometry

Traditional overlay lyrics lock to a wide box that wastes screen estate. MusicGan runs real-time text layout measurements on each lyric update, morphing the island boundary to hug the text between 190px and 500px.

  • Sub-pixel string width measurement in memory
  • Organic BackEase spring transition on phrase change
  • Balanced 28px icon channels for strict center alignment

Deterministic Media Hooking

Rather than relying on brittle browser extensions or heavy background servers, MusicGan executes low-level Win32 window enumeration paired with Windows 10/11 GlobalSystemMediaTransportControls.

  • 0% CPU idle consumption with 450ms dispatch timer
  • Zero external credentials or user login required
  • Global virtual key simulation for universal Play/Pause/Skip

Unapologetically Native

Most modern desktop tools bundle an entire copy of Chromium and Node.js just to show a small widget. MusicGan is compiled directly with Microsoft .NET Framework C# compiler into a lean Windows PE binary.

  • Runs out of the box on standard Windows 10 & 11
  • Zero node_modules, zero npm supply-chain dependencies
  • Direct hardware-accelerated DirectWrite text rendering
